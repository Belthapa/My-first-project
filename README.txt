# VibeCheck Website Starter

This is a responsive HTML/CSS/JavaScript starter based on the supplied VibeCheck screenshot.

## Files
- index.html — page structure
- style.css — complete responsive styling
- script.js — cart, wishlist, size selection, search and newsletter demo

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Install the VS Code extension **Live Server**.
4. Right-click `index.html` → **Open with Live Server**.

## Important
The model/product pictures in the screenshot are represented by CSS placeholders in this starter.
For the real store, replace those areas with your own product/hero images and connect:
- product database
- cart
- login/account
- payment gateway
- order tracking
- shipping
- admin dashboard

The layout is intentionally close to the supplied reference while remaining an original implementation.
